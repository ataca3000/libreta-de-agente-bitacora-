# Structured Event Logs

Structured, auditable logs generated during system evolution.

* `decisions/`: Architecture Decision Records (ADRs) explaining *why* a design choice was made.
* `descubrimientos/`: Chronological record of technical findings and newly introduced concepts.
* `fallos/`: Post-mortem autopsies and root-cause analyses of bugs or failures.
* `simulations/`: Results of pre-execution dry runs, stress tests, or simulations.
