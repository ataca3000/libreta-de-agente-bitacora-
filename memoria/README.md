# Agent Persistent Memory Layer

External document cache serving as the assistant's long-term disk memory.

* `causal/`: Documented cause-and-effect relationships within the codebase.
* `episodico/`: Records of major milestones, architectural refactors, or critical events.
* `identity/`: System context, operational scope, and agent role definitions.
* `long_term/`: Consolidated, immutable domain knowledge.
* `procedimental/`: Step-by-step guides and internal SOPs for recurring tasks.
* `short_term/`: Volatile context cache for the current active working session.
* `procedimientos/`: Standardized operational procedures.
* `basura/`: Deprecated docs or pending purges.
* `vault/`: Immutable, citable reference data.
