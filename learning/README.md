# Learning & Adaptation Layer

Tracks dynamic system feedback and operational learnings.

* `confianza/`: Decision certainty metrics and confidence scoring.
* `penalizaciones/`: Logged logic errors and discarded paths (to avoid failure loops).
* `recompensas/`: Validated, highly successful code patterns and solutions.
* `incertidumbre/`: Unverified edges, open edge cases, and pending audit zones.
